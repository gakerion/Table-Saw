# 3D-Printed Mini Table Saw — 775 Motor with Speed Control

A compact DIY mini table saw built around a 775 DC motor, with a 3D-printed housing and tabletop. This project combines printed structural parts with metal shafts, bearings, pulleys, and a timing belt.

The motor drives a separate cutting shaft through a belt-and-pulley system, with the drive components housed underneath the removable tabletop. The photos show my assembled build and its internal layout.

### Features

- Compact 3D-printed enclosure with ventilation slots.
- Removable tabletop for access to the motor, belt, and wiring.
- Belt-driven cutting shaft supported by bearings.
- Integrated motor speed controller with an externally accessible adjustment knob.
- Slotted tabletop for positioning guide attachments.
- Screw-fastened construction with threaded inserts for the tabletop.

### Motor and controller

My build uses a **775 DC motor** with a motor speed controller mounted inside the enclosure.

**For the motor used in this build, the controller should be rated for at least 10 A continuous current.** This refers to its continuous rating, rather than an advertised peak rating. The controller and power supply must also match the operating voltage of the motor.

### Additional hardware

Alongside the printed parts, the build requires a motor, compatible controller and DC power supply, belt and pulleys, metal shaft, bearings, cutting disc and mounting hardware, fasteners, threaded inserts, and wiring.

The photographs provide a reference for the assembled layout and component placement.
